星分翼轸

　　“星分翼轸，地接衡庐。”出自唐代王勃的《滕王阁序》。

古人把地上主要的封国和天上28宿做了映射，滕王阁所在的南昌在江西省，也就是古代的楚地，楚地在中国南方，对应天上的星图的南方巳火区的翼宿、轸宿之间。这就是星分翼轸的意思。————知乎/董三碗

　　取“星分”为昵称用意即为：认为自己也会是天上星宿在人间的分野。

　　尽管“星分”并非完全收敛的一个名词性质的词语，其含义也与我所期望的含义有所区别，但这并不我妨碍取“星分”为名。“星分”于我，可以意为我是星辰在人间的投射，也可以指代星辰的光辉笼罩于我。

　　这就是星分的由来。

关于 XingfenD

　　我的大学期间遇到了一位特殊的人，尽管与我并无血缘关系，但我常与其以姐弟相称。有一次她打趣般得为我起了英文名：星分弟的空耳——“芬迪”。

　　在我取 Github 用户名时，本想直接起作 Xingfen，但自觉看着有些单调，考虑到上面的“取英文名”，鬼使神差般地在 Xingfen 的末尾加了一个大写D。

　　这就是 github.com/XingfenD 的由来。

关于 Fendy

　　源于“芬迪”的空耳英文名，由于注册某些境外网站时需要英文名，以 xingfen 汉语拼音作为英文名，显示出来时不太连贯，因此以 fendy 作为英文名。

关于 xf

　　星分的首字母缩写，本人绝大多数社交媒体昵称都叫 xf.。

关于“挽星”与“晚星”

　　源于“晚星”。“特别的人”在直播给朋友看时曾集思广益征集粉丝牌名。我以两人昵称中包含的“晚”“星”拼成“晚星”，奈何粉丝牌名似乎必须三个字，并未被采纳。于是我替“晚”为“挽”得到“挽星”，用于某些平台的昵称，包含挽起另一人，并肩同行的愿望，遗憾的是似乎总是会落空。

关于远楒

　　“远楒”为我名字的缩写寻找相同声母的字组成的词，最初为“椴远楒”——空耳为“断远思”。原意为希望自己能斩断渺不可及的思念，现在“远楒”被单取出来使用，用于表达深入的思考。具体可以参考本站关于页面。

何以为我？

　　我希望有人能愿意了解我，也常落泪于真心难寻，郁结之时常自问“何以为我？”。

　　“记得来时路，方知向何生”。将我自己记录于此，不求他人认真阅读，只愿未来的我能从这里寻找到最初的样子。
