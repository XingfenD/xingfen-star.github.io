本文展示了如何在博客中使用 APlayer 音乐播放器。

实际演示

下面是一个真实的播放器示例（使用外部音频源）：

基础用法

最简单的用法，只需要提供歌曲名和音频地址：

1

{{< aplayer name="歌曲名" artist="艺术家" url="音频地址" >}}

本地资源（Page Bundle）

把音频文件和博文放在同一个目录下：

content/post/your-post/
├── index.md
├── forest.mp3        ← 音频文件
├── cover.jpg         ← 封面图片
└── song.lrc          ← 歌词文件

使用相对路径引用：

1

{{< aplayer name="森林之声" artist="大自然" url="forest.mp3" cover="cover.jpg" >}}

外部网络资源

直接使用完整的 URL 地址：

1

{{< aplayer name="示例音乐" artist="艺术家" url="https://example.com/music.mp3" cover="https://example.com/cover.jpg" >}}

带歌词的播放器

支持 LRC 格式的歌词文件：

1

{{< aplayer name="歌曲" artist="歌手" url="song.mp3" lrc="song.lrc" >}}

自定义样式

可以自定义主题颜色：

1

{{< aplayer name="红色主题" artist="艺术家" url="music.mp3" theme="#e74c3c" >}}

自动播放

设置 autoplay="true" 让音乐自动播放（注意：大多数浏览器会阻止自动播放）：

1

{{< aplayer name="背景音乐" artist="轻音乐" url="bgm.mp3" autoplay="true" >}}

完整参数

参数 说明 默认值
name 歌曲名 Unknown
artist 艺术家 Unknown
url 音频文件路径 必填
cover 封面图片 空
lrc 歌词文件 空
theme 主题色 #2980b9
autoplay 自动播放 false
id 自定义 ID 自动生成

注意事项

  1. 音频格式：推荐使用 MP3 格式，兼容性最好
  2. 文件大小：本地音频文件不要太大，建议压缩后小于 5MB
  3. 版权问题：使用外部资源时请注意版权
  4. 自动播放：现代浏览器通常会阻止自动播放，用户需要先与页面交互
