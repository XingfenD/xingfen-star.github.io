2026-06-22

Added / 新增

  • 摘抄（excerpt）内容类型：archetype、列表页瀑布流布局、详情页元数据展示
  • 摘抄示例内容（有图/无图两种形态）
  • 摘抄快速创建脚本 deploy/scripts/new-excerpt.sh

Fixed / 修复

  • 摘抄 _index.md 菜单图标 quote.svg 不存在，改为 collection
  • 摘抄创建脚本标题特殊字符（引号、斜杠）未清理，导致 TOML 解析失败或生成嵌套目录
  • 摘抄创建脚本输出路径改为相对路径，与 new-micro.sh 保持一致
  • 摘抄列表页 source/author 为空时 <br> 产生多余空行，改用 CSS 控制日期换行
  • 摘抄列表页无内容时显示空状态提示

2026-06-13

Added / 新增

  • APlayer 内联播放器：懒加载（IntersectionObserver）、自动提取 ID3 封面（jsmediatags + fetch）、单次请求优化（封面提取与播放共用同一份音频数据）
  • 博客 frontmatter 支持 music 字段，响应式 mini 播放器（桌面端右侧边栏 / 移动端正文上方），首次交互自动播放，循环播放，进度调节，自动提取 ID3 封面
  • APlayer 加载占位：fetch 音频期间显示歌名 + 旋转加载图标

Fixed / 修复

  • APlayer 播放器提前于正文内容显示：将其纳入主题 scroll reveal 动画体系
  • APlayer autoplay 参数字符串 "false" 被当作 truthy 的问题
  • APlayer shortcode URL 解析：relURL 对 / 开头路径不拼接 baseURL 子路径，改用 path.Join 确保子路径前缀正确
