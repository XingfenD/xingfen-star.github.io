2026-06-15

Added / 新增

  • frontmatter music.disable 属性：设为 true 时禁用音乐播放器，等同于未配置 music

Fixed / 修复

  • blockquote 内图片覆盖左侧高亮边框：.gallery 的全宽出血负 margin 导致画廊溢出 blockquote 边界，通过 overflow: hidden 裁剪 + 中和 gallery 负 margin 修复

2026-06-13

Added / 新增

  • 侧边栏 mini 音乐播放器组件（响应式：桌面端右边栏 / 移动端正文上方）
  • 文章卡片音乐标识：frontmatter 配置 music 时在列表页显示音符图标和歌名
  • 音乐播放器加载状态：fetch 音频期间播放按钮显示旋转动画
  • 音乐播放器封面淡入：图片加载完成后淡入显示，占位符延迟隐藏避免跳动
  • 冷加载封面不显示：两个实例（正文+侧边栏）各自发 fetch 导致只有一个拿到封面，改为共享同一 fetch Promise

Changed / 变更

  • scroll reveal 选择器新增 .article-content > .aplayer-container

Fixed / 修复

  • 侧边栏播放器暗色模式下播放/暂停按钮文字颜色不可见
  • APlayer 暗色模式下背景和歌曲名颜色不适配
  • 音乐播放器 URL 解析：relURL 对 / 开头路径不拼接 baseURL 子路径，改用 path.Join 确保子路径前缀正确
  • 音乐播放器延迟加载：页面加载时不再立即下载整个音频文件，改为首次用户交互时才 fetch，避免大文件阻塞页面渲染
  • 音乐文件双重请求：封面提取 fetch 与 audio 播放各请求一次，改为单次 fetch 后复用 blob URL

2026-06-10

Changed / 变更

  • 代码块 macOS 窗口风格扁平化：标题栏渐变改为纯色、阴影减弱、红绿灯圆点缩小
  • 代码块语言标签字体改为无衬线体（system-ui）
  • 无语言代码块也显示 macOS 窗口装饰和复制按钮

Fixed / 修复

  • Mermaid 图表缺失正文淡入动画（wrapper 创建后重新注册 scroll reveal）

2026-06-06

Added / 新增

  • 站点导航卡片样式（sitemap-card）
  • 左侧边栏站点导航入口（map 图标）
  • footer-links 样式

Fixed / 修复

  • 移动端侧边栏站点导航链接的列表序号标记

2026-06-03

Changed / 变更

  • 关闭文章阅读时长（readingTime）显示
  • 重构 Mermaid 全屏查看器为极简精致风格，支持亮色/暗色主题切换
  • 自研平移/缩放控制，移除 panzoom 外部依赖
  • 触摸板双指滑动→平移，捏合→缩放，行为分离

2026-05-31

Added / 新增

  • 入场动画（Entrance Screen）：全屏星空首页，sessionStorage 控制单次显示
  • 合集分类法（Collection Taxonomy）：系列文章条 + 前后篇导航
  • 时间线归档（Timeline Archives）：按年月分组的垂直时间线视图
  • 文章密码保护（Password Gate）：SHA-256 哈希验证，集成到文章卡片结构
  • 友情链接页面（Links Page）：卡片网格布局
  • 阅读进度条（Reading Progress Bar）：文章页顶部细条
  • 回到顶部按钮（Back to Top）：滚动 300px 后显示
  • 滚动渐显动画（Scroll Reveal）：文章内容元素 fade-in + slide-up
  • macOS 风格代码块：红黄绿圆点头部 + 语言标签 + 毛玻璃复制按钮
  • 双栏 Compact 列表：桌面端 2 列网格
  • 微博客样式（Microblog）：.micro-list、.micro-home-card、.micro-article
  • 当前文章标签 Widget（cur-tags）
  • hidden = true 文章全局过滤（pages.html 统一处理）

Changed / 变更

  • 基础字体改为 Noto Serif SC（CJK 衬线）
  • 归档页面重构：时间线替代 compact 列表，支持分类/合集/标签瓷砖
  • 标签瓷砖尺寸缩小（160×60px），适合纯文本场景
  • 字体加载仅 Lato（Noto Serif SC 走本地系统字体）
  • 代码块 CSS 变量全面重写（macOS 头部、滚动条、复制按钮）
  • .section-title 链接可点击，hover 变色
  • .subsection-list 负 margin 在归档页面消除，避免覆盖标题

Fixed / 修复

  • 密码保护文章缺少卡片容器（背景、圆角、阴影）
  • 归档页合集/标签标题链接不可点击（with 块上下文问题）
  • 空分类/合集/标签仍显示的问题
